# Waveshare Pico 1.3 LCD Case by Tomáš Plass

`waveshare-13-pico-lcd-case-tomas-plass.stl`: the v0 case, as downloaded from
[Printables model 1322102](https://www.printables.com/model/1322102-waveshare-pico-13-lcd-case).
Both halves in one mesh, side by side. License CC BY-NC 4.0 (remix ok, attribution required, no
commercial use). This is the print Austin verified on 2026-09-05.

It lives here as the reference: `case/waveshare-raspberry-pi-pico/waveshare-raspberry-pi-pico.step` is a parametric recreation of
it (Onshape, by Jason McPheron, same license), and `tools/step check` measures the recreation against
this mesh. Print `case/waveshare-raspberry-pi-pico.stl`, not this.
